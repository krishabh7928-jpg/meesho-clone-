# Meesho Clone - Online Shopping for Quality Products at Lowest Prices

> **A Complete, Polished Indian E-Commerce Web Application (Meesho Clone)**  
> **Project Type:** B.Tech College Major / Minor Coding Project Demonstration  
> **Tech Stack:** Semantic HTML5, CSS3 (Custom Design System & CSS Grid), Pure Vanilla JavaScript (ES6+)  
> **Execution:** 100% Client-Side. No installation, build tools, or backend required. Runs directly in any web browser.

---

## 🌟 Project Overview

**Meesho Clone** is a responsive, feature-rich web replica of India’s favourite social-commerce and e-commerce platform, **Meesho (meesho.com)**. Specifically engineered as an impressive B.Tech college coding project, it reproduces Meesho's iconic magenta/pink branding, factory-direct wholesale pricing structure, Indian ethnic apparel showcase (sarees, kurtis, juttis), M-Trusted supplier badges, multi-category navigation, slide-over drawers for Cart & Wishlist, interactive Quick View modal, and client-side checkout with complete input validation and `localStorage` persistence.

## 💎 Authentic Meesho Features & Capabilities

### 1. Meesho UI/UX Branding
- **Signature Meesho Logo:** Distinctive lowercase `meesho` typography with a `CLONE` project pill.
- **Color Palette:** Authentic Meesho Magenta (`#9f2089`) with bright pink (`#f43397`), clean white cards, and subtle purple accents.
- **Top Promotional Bar:** Meesho Mahamahotsav ticker, coupon `MEESHONEW`, Free Delivery notice, and links for *Download App* and *Become a Supplier*.
- **Meesho Search Bar:** Iconic search box with *"Try Saree, Kurti, Shoes or Search by Product Code..."* and live thumbnail suggestions.
- **Mobile Bottom Navigation Dock:** Replicates the native Meesho Android/iOS app feel with Home, Categories, Wishlist, Cart, and Account icons.

### 2. Multi-Department Category Strip
- **8 Core Meesho Categories:**
  1. *Women Ethnic* (Sarees, Anarkali Suits, Kurtis)
  2. *Women Western* (Maxi Dresses, Tops, Jeans)
  3. *Men* (Linen Shirts, Denim Jeans, Oversized Tees)
  4. *Bags & Footwear* (Handcrafted Mojari Juttis, Crossbody Handbags)
  5. *Home & Kitchen* (Granite Cookware, Jaipuri Bedsheets, Insulated Bottles)
  6. *Beauty & Health* (Vitamin C Glow Serum, Velvet Lipsticks, Coffee Scrub)
  7. *Jewellery & Accessories* (Kundan Choker Sets, Aviators, RFID Wallets)
  8. *Electronics* (ENC Wireless Earbuds, AMOLED Smartwatch, Powerbanks)

### 3. Product Catalog ("Products For You")
- **22 Realistic Products:** Genuine Indian fashion titles (e.g., *Charvi Sensational Embroidered Kurta*, *Aishani Pure Kanjeevaram Silk Saree*, *Rajasthani Handcrafted Juttis*).
- **Pricing & Discounts:** Realistic Indian Rupee pricing (`₹199` to `₹1,199`), strike-through original prices, and high discount labels (`50%–70% OFF`).
- **Meesho Badges:** `M-Trusted`, `Free Delivery`, `Under ₹299`, and star rating pills (`★ 4.5`).
- **Live Search & Autocomplete:** Real-time search by product name, category, or description with dropdown suggestions and a one-click clear button.
- **Sorting Options:**
  - Popularity (Default)
  - Price: Low to High
  - Price: High to Low
  - Highest Rated
  - Biggest Discount
- **Smart Filter Tabs:** *All Products*, *Trending (🔥)*, *M-Trusted*, *60%+ OFF*, and *Under ₹299*.
- **Empty State Recovery:** Illustrated empty state with a *"Reset All Filters"* button.

### 4. Interactive Modals & Slide-Over Drawers
- **Product Details (Quick View Modal):** High-resolution image view, verified supplier badge, star ratings, stock status, detailed specs, and interactive quantity selector (`-` / `+`).
- **Shopping Cart Drawer ("My Meesho Bag"):**
  - Slide-in side drawer animation.
  - Automatic quantity incrementing (prevents duplicate rows).
  - Dynamic Free Delivery progress bar (unlocks free delivery at ₹499+).
  - Promo Coupon code validation (`MEESHONEW` for flat ₹150 OFF, `MEESHO100` for flat ₹100 OFF, `FESTIVE20` for 20% OFF).
  - Complete price breakdown: Bag Total (MRP), Product Discount, Delivery Fee, Coupon Discount, and Final Payable Total.
- **Wishlist Drawer:** One-click heart toggle on product cards, animated badge counters, and direct "Move to Cart" button.
- **Client-Side Demo Checkout:**
  - Delivery address form with Indian phone (+91 10-digit) and 6-digit PIN code validation.
  - Order mini-summary with live item counts.
  - Payment method selector: Cash On Delivery (COD) or Instant UPI Demo.
- **Order Confirmation Modal:**
  - Animated checkmark badge.
  - Unique generated Order ID (e.g., `MEESHO-ORD-2026-94821`).
  - Order date, estimated delivery time (3-5 business days), and shipping summary.
  - Automatically clears the cart and registers order into Order History.
- **User Profile & Order History:**
  - View all past demo orders placed during the session.
  - View saved default delivery addresses.
  - Copy promo coupons directly.
- **Floating Toast Notifications:** Instant feedback for adding to cart, wishlisting, removing items, and copying coupon codes.

## 🎓 Viva Voce / Demonstration Talking Points

Here are answers to potential questions your evaluator or professor might ask:

### Q1: Why is this project model inspired by Meesho?
> **Answer:** "Meesho pioneered Indian social commerce by connecting consumers directly to local manufacturers and weavers, eliminating traditional middleman commissions. This clone incorporates Meesho's authentic design language: factory-direct pricing in INR, Cash on Delivery, free shipping indicators, verified supplier trust badges, and Indian ethnic fashion."

### Q2: How does data persistence work without a backend database?
> **Answer:** "We utilized the HTML5 `localStorage` Web API. When a user adds an item to their cart, toggles a wishlist item, or places an order, the application serializes the JavaScript state array into a JSON string via `JSON.stringify()` and saves it under dedicated keys (`meesho_cart`, `meesho_wishlist`, `meesho_orders`). On page reload, `JSON.parse()` restores the user's active session seamlessly."

### Q3: How is duplicate prevention handled in the shopping cart?
> **Answer:** "In `script.js`, the `addToCart(productId, quantity)` function uses `Array.prototype.findIndex()` to check if the product ID already exists in the cart array. If found, it increments the existing quantity by the selected amount rather than appending a duplicate entry. If not found, it pushes a new item object."

### Q4: How is mobile responsiveness implemented?
> **Answer:** "We used modern CSS media queries combined with CSS Grid (`repeat(auto-fill, minmax(...))`) and Flexbox. On desktops, products display in 4 columns. On tablets, they adapt to 3 columns, and on mobile phones (<=768px), they adapt to a 2-column grid like real e-commerce apps (Meesho/Myntra). We also added a fixed bottom navigation dock for mobile viewports."

### Q5: How do the filters and search operate together?
> **Answer:** "All filters run through a centralized pipeline function `applyFiltersAndSort()`. It takes the master product list and chains sequential filtering conditions: category matching, substring search matching, view tab filtering (trending/bestseller/discount), and finally applies the active sort comparator before re-rendering the DOM."
